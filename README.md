# 啟殷 × 芷蕎 婚禮完整司儀手卡網頁版

專為 2026年10月10日 啟殷與芷蕎婚禮設計的舞台手機專用雙人司儀手卡與完整流程提示網頁。

🔗 **線上瀏覽網址**：https://jtchen1225-a11y.github.io/wedding-mc/

## 📱 核心功能與舞台專屬設計

1. **防休眠螢幕長亮 (Screen Wake Lock API)**：
   - 解決司儀在台上拿著麥克風與手機時，螢幕自動變暗或鎖定的困擾。
   - 頂部設有長亮狀態指示與手動開關。

2. **雙人視角自由切換 (Role Filtering)**：
   - **👥 雙人對稿**：完整顯示兩人台詞與互動。
   - **👩‍💼 表姐專屬（主講視角）**：高亮表姐台詞，弱化淡化表姐夫台詞，便於抓節奏。
   - **👨‍💼 表姐夫專屬（配合視角）**：高亮表姐夫接位與笑點，弱化表姐台詞。

3. **兩種觀看模式**：
   - **📜 劇本捲動模式**：包含現場流程速覽表、完整提示、時間軸與所有環節對白。
   - **🎴 逐張手卡模式 (Teleprompter Mode)**：大字體單卡顯示，支援左右滑動切換上一張／下一張，舞台盲讀不跳行。

4. **高對比舞台防反光深色主題**：
   - 預設 OLED 純黑背景，減少藍光照射到司儀臉上的反光，字體清脆高對比。
   - 提供「🌙 舞台深色」、「⚡ 極致高對比」、「☀️ 喜慶白金」三種配色。

5. **即時時鐘與倒數小幫手**：
   - 頂部導航列顯示即時時鐘（時:分:秒），司儀無需切出畫面看時間。
   - 內置「切蛋糕 3-2-1」與「乾杯 1-2-3」倒數動畫特效輔助。

6. **舞台提示醒目標記（切勿讀出）**：
   - 所有【舞台提示】、現場 Cue 及音響燈光指令均以醒目虛線方框與標籤標示，嚴防誤讀出聲。
   - 特別標記「停頓 1–2 秒等笑聲」等節奏提示。
